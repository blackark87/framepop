# Framepop

밝은 한국어 영상 제작 작업실 목업. dist/index.html을 정적 서버에서 제공합니다.

데모: 기획 확정 → 타임라인 확정 → 참조 확정 → 순차 영상 생성/QC. 7번 QC 실패 후 재시도하면 계속 진행합니다. 실제 계정 인증, 영상 생성, 얼굴 분석은 수행하지 않습니다. 프로젝트 및 설정은 브라우저 localStorage에만 저장됩니다. 비밀값을 입력하지 마세요.

컬러 차트: dist/palette.svg, 사이트 #palette.
검증: node check.cjs. 브라우저 시각/클릭 검증은 별도로 수행하지 않았습니다. WebMCP는 지원 브라우저에서 탐색 도구를 등록하며 실제 지원 컨텍스트 검증은 수행하지 않았습니다.

API 명세는 실제 서버 구현을 위한 초안입니다. 목업에 API 서버는 없습니다.
